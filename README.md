# Movies-Data-Analysis-
Conduct a research on factors affecting movie box office success (e.g., genre, ratings, cast, duration)

Key Details
Source: Scraped from IMDb (Internet Movie Database)
Time Period: Covers movies released mainly from 1986 to 2016
Number of Movies: Approximately 6,820 to 7,666 entries
Main File: movies.csv 
Purpose: Great for analyzing movie success factors like box office earnings, budgets, ratings, and more.
Kaggle Link: title.basics.tsv.gz (titles, genres, runtime): ~300–500 MB compressed.


Final Conclusion:
Higher budget → usually much more revenue.
Good ratings (7+) → help a lot.
Runtime around 100–150 minutes → often best.
Genres like Action, Adventure, Animation → make the most money.
